# 审核表模板

给决策者的文件。他在笔记软件里直接勾选、写批注；你读取勾选结果再行动。

```markdown
# <主题>评审

> 起因：<决策者的原话或触发事件>。
> 产物：<目录>。体验地址：<可点开的地址>，<先看哪里>。

## 一、结论
<一段话：推荐什么、为什么。坏消息放最前面。>

## 二、方案对比
| | 立场 | 证明了什么（实测数字 / 截图） | 不足 |
|---|---|---|---|
| A | … | … | … |
| B | … | … | … |

**推荐：<组合或单选>。** 理由分条写，每条对应需求或已有决定。

## 三、需要你拍板的取舍
<只列真正需要他决定、会影响后续的取舍；其余可以直接按推荐处理的不列。>

## 四、请决定
- [ ] <推荐项>（推荐）
- [ ] <备选项>
- [ ] 同意后，由我 <下一步动作>
```

## 勾选之后

1. 读取勾选结果和批注；勾选与批注冲突时先问。
2. 写正式的决定记录：编号、决定内容、理由、后果（包括决策者的口头更正）。
3. 在审核表末尾追加：

```markdown
## 五、结果（<日期>）
决策者决定（见 <决定编号>）：
- …
```

4. 按决定执行；没勾的不动。
