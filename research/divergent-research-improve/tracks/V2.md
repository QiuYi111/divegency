## 5. 反向激励（新规则自己制造的）

按"最省力合规路径"排序，每条都有上面的实测支撑：

1. **为过 artifact 检查而造空文件**。29 号只问存在性 → `touch run.log` 是全局最便宜的动作，比真跑实验便宜 4 个数量级。我的 0 字节 `run.log` 同时"支撑"了 3 条 pass。**改法**：存在性 → 非空 + 内容结构（命令/版本/输出）。
2. **用 URL 逃避 artifact 检查**。`is_url` 直接返回 None，连"无法核验"的 warning 都不发（因为 `exists is None and not is_url` 被短路）。这比空文件更隐蔽：`variant_b` 在 `--strict` 下**零 warning**。**改法**：pass 必须本地 artifact，URL 只允许出现在 sources。
3. **为过 finalists 检查而编造 witness**。38 号是纯文本存在性检查，成本 30 秒，收益是"三条路线原理不同"的结论。**改法**：结构化预测字段 + 相反性断言（见 4.5）。
4. **为躲签名撞车而给预测加噪声**。39 号只比对元组相等，于是"把 P1 从 down 改成 no-change"就能造出独立签名。我的三个同族候选因此拿到 3 个不同签名（`distinct_prediction_signatures: 3`）。这是**主动鼓励造假**的：写得越随意，看起来越多样。**改法**：签名撞车从 warning 升为"必须新增判别问题"，同时校验 predictions 与 mechanism 的因果一致性（至少要求 candidate 给出"为什么是这个方向"的 `prediction_rationale`）。
5. **干脆不写 predictions**。`mutant_no_predictions` 在 `--strict` 下 EXIT=0 且零提醒，因为 39/40 号都被 `len(signatures) > 0` 短路。**少写比多写安全**，与"先想后搜、写下判别问题"的意图正相反。**改法**：声明了 probes 就要求每个候选写全，缺失即 error。
6. **不写 checked 更省事**。`checked=false` 零惩罚，于是"只见到标题"是安全的诚实；但 `result=pass` 又强制要 checked 一手证据 → 想宣称通过就必须至少伪造一条引文。**改法**：让"未核实"在 stats 里可见且进最终交付（现在 `families_with_checked_primary_evidence: 0` 只是个数字，没有任何措辞约束）。
7. **`result=not-run` 让整库零成本通过**。`variant_d` 证明：1 个方向、2 个候选、0 条已核实来源、无 tracks，`--strict` 退出 0。**"结构检查通过"与"做过研究"完全解耦**。这是最深的一条：绿色不携带任何关于"是否发生过研究"的信息。
8. **`dead_ends` 免费**。41 号只查 route/why，`evidence` 字段从不校验（我写 `runs/e2e.log`，文件不存在）。伪造一份漂亮的失败清单成本≈0。
9. **故意少报视角**。budget=standard 要求 4 视角（SKILL §0.4），但 `variant_d` 只写 1 个方向仍绿。少报视角不会有任何提醒，因为 "gaps" 只在"方向无候选"时触发。

## 6. 结论

- 新版 checker 在**结构一致性**上是可靠的：字段、引用完整性、finalists 双向存在性、exit code 语义都正确，并且脚本自己印了免责声明（"并不代表引用、原理和测试结果真实或正确"），这句是真的——我这份 100% 虚构的方案库在默认模式 exit 0，在 `--strict` 下也能 exit 0（`variant_b` / `variant_d` / `mutant_hardened` / `mutant_no_predictions`）。
- 漏洞集中在**三类"存在性代替真实性"**：文件存在代替内容、字符串存在代替判断、字段存在代替预测。以及一处**激励倒挂**：少写预测比多写安全。
- 修复不需要新流程，全部是"把已有的检查做深一层"：locator 复用 artifact 的存在性检查；artifact 加非空与共用检测；differentiation 加 `prediction_self != prediction_other`；probes 声明后 predictions 必填；签名撞车升级。合计约 15 行 Python + 3 句 SKILL 文本。
- **未做/未验证**：未测 `test_check_portfolio.py` 是否覆盖这些 mutant（我只跑了 checker）；未测真实多 Agent 会话里 L1/L2/L3 是否可核（脚本完全不读 tracks，所以本轮无法从产物侧验证独立性等级）；"审计耗时"里标估算的部分没有秒表，不作为测量值。
