# D6 首轮独立研究：把「自述」换成「可抽查的产物」

日期：2026-10-25　｜　Agent：D6（不预设视角）　｜　对象：skills/divergent-research

## 0. 一句话机制主张

**这个 Skill 的规则几乎全是“行为要求”，但每条规则的证据都是“作者自述”**：`checked: true` 是自己打的布尔值，`mechanism_key` 是自己起的名字，“已核实”是自己写的三个字，`pass` 只要求 `artifact` 非空。因此退化不是“难以发现”，而是**发现成本高于收益**，于是默认发生。

两个改动都只用一条杠杆：**把不可核的自述，换成“做了就便宜、没做就贵且可抽查”的产物**。

1. **举证责任倒置**（多样性）：现在“两条路线不同”是免费的，“相同”才需要证明——而否定命题没人能证明，所以一切都通过。改为：默认同族，主张不同的一方必须交出一个**判别性观察**（能执行、且两方事先预测相反的输入/工况/查询）。这同时给出非计数多样性判据（S3）和语义去重的机器可查锚点。
2. **原文锚点**（证据）：把 `checked: true` 升级为“逐字引文 + 可定位位置 + 支持的子结论”。做过的人 30 秒能抄出来；没做过的人只能编，而编造的引文可以在一次 grep 里被证伪。

为什么这能改行为：在时间压力下，Agent 的默认策略是产出更多文字，因为所有现有检查都能靠打字满足。新规则让“打字”不再足够，而让“做事”成为最省力的通过方式——**不是加强惩罚，而是改变通过路径的成本结构**。

## 1. 候选机制（按信息量排序）与被否掉的

| # | 机制 | 判断 | 依据 |
|---|---|---|---|
| M1 | 判别性观察作为“不同原理”的操作定义 + 举证责任倒置 | **采纳**（核心） | Si et al. 2024 摘要明确指出 LLM ideation agent “lack of diversity in generation” 是未解问题；Platt 1964 的“强推断”把“多个竞争假设 + 关键实验”作为方法核心（仅核对元数据，未读全文，见 §6） |

### 1.1 主动放弃：给每条路线强制一个最小实验

原本想写：“每条路线在进入汇总前必须跑一个最小实验，否则视为空谈。”放弃的三条理由：

1. **模式不匹配**。`facts`（查清事实）与 `decision`（选型）在很多任务里没有可控实验台，强制实验会逼 Agent 去造一个“看起来像实验”的东西。
2. **R1 拦不住伪造**。脚本能查 `artifact` 文件是否存在，但 Agent 可以创建一个空文件或一句 log。把“跑没跑”变成硬门槛，改进的是伪造动机，不是证据质量。
3. **成本超出 S4**。`quick` 下 3 路 × 1 个实验，比现状重得多；而真正的实验预算应由 `experiment-protocol` 按任务决定。

替代品是判别性观察：它保留“可检验”的内核（必须写出会观察到什么），但允许暂不执行，把“要不要花这笔钱”留到汇总时按信息量决定。另两个被否掉的：embedding 相似度当多样性指标（混淆措辞与机制，可被换词刷高，且要额外模型调用）；增加“魔鬼代言人”Agent（只是让另一个 Agent 复查措辞，仍查不到机制）。

**替换后**：

代价：汇总者要为每对最终候选写 3 行；换来的是“同族/不同族”从审美判断变成可复核判断。副作用：可能把“暂时写不出”的早期想法过早合并 → 用“暂不执行但必须可执行”和“执行后相同才合并”两条刹车。

## 4. 失败与未覆盖

1. **web_search 在本会话不可用**（DeepSeek 401 认证失败）。领域版图只能靠直接 web_fetch 已知入口（arXiv abs 页、arXiv API、Europe PMC API）完成，**没有做关键词检索**，因此可能漏掉 2025–2026 年关于多 Agent 想法同质化的新工作。已把“未做系统检索”当作本报告的主要局限。
2. R2 只能证明“写了引文”，不能证明“引文真出自该文献”。伪造的引文仍可能通过；唯一防线是复核者按 locator 抽查。可进一步做（未做）：要求 quote 前后各 10 字也贴出，或要求 PDF 页码与文本层一致。
3. “判别性观察”可被写成看似合理但实际不可执行或不区分的形式（例如“在不同负载下测一下”）。脚本只能查字段齐全，**无法判断它是否真的可执行、预测是否真的相反**——这仍需人看。缓解是要求预测写成可观察量，但这是弱约束。
4. 首轮隔离与“跟谁比”存在张力。处理方式：首轮只与自己次优方案比（vs: "self:..."），跨路配对推迟到汇总；代价是首轮的判别性观察信息量较低。
5. 没有真实 Agent 的 A/B 实验。所有“会改变行为”的判断都是机制推理 + 规则层对照，不是效果测量。
6. 未评估新增字段对 quick 模式的实际耗时；估算为每路 +3~5 分钟，但未测。

### S2 可执行
每条新指令都写成“触发条件 + 动作 + 产物”：判别性观察（产物：3 行字段）、锚点（产物：引文+位置）、顺序封存（产物：只读的 track 文件）、闸门（产物：三个文件/行指针）。全部不需要额外工具；脚本是纯标准库。

### S3 多样性（非计数）
判据是**判别性观察**：两条路线不同 ⇔ 存在一个可执行的观察使两者预测相反/不重叠。第三方复核只需读 3 行并判断“这个观察真能区分吗、能不能跑”。不依赖 Agent 数、字数、来源数。

### S4 成本
- SKILL.md：三处是**整段替换**，不新增行（82 行不变）；实测两处主替换字符数 +362（3638 → 4000，+10.0%），加上另两处小改约 +520（≈+14%），低于 25% 上限。
- quick：不加 Agent、不加轮次；只要求每个最终候选 1 条锚点、finalists 之间 1 对判别性观察。新增的是汇总时的 5 分钟写作，不是搜索预算。
- 新增文件：无（原型放在研究记录里，不进 skill）。

### S5 可验证
- 脚本断言：§3 的三夹具 + 3 个单测（已运行）。
- 走查样例：拿任何一个真实 portfolio，把 artifact 改成不存在的路径、删掉 anchors，确认从 0 error 变为 2 error。
- 对照实验（建议汇总方做）：同一任务、同一模型，两组各 3 路，A 组用现版 skill，B 组用改后 skill；由第三方盲评“最终候选里真正不同原理的条数”与“能对上原文的引文比例”。生效时观察：B 组 R3 报错次数先升后降（先暴露旧问题），最终候选数下降但“可区分条数”不降。

### S6 保留内核
同一完整目标（agent-contract 未动其核心）、宽泛视角（未改）、首轮隔离（§2.2 加强而非削弱）、缺口补搜（未改）、证据与独立评测（§2.4/§2.5 加强）。判别性观察只在汇总期跨路配对，不破坏隔离。
