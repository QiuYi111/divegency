## 0. 一句话主张

现在这个 Skill 让 Agent“多写几个候选、多派几个 Agent”，但**没有任何机制能判定两个候选是否真的不同**，也没有任何规则决定“下一笔预算给谁”。我把它换成一条可判定的判据加一条可执行的分配规则：

> **派发前先锁定 4–6 条判别探针；候选的价值不是它的名字和分数，而是它在探针组上的预测签名。签名相同 = 同一族（在现有判据下不可区分）。预算按“这次投入能改变哪一族的判定”分配，跨族不淘汰，只在族内剪枝。**

这条改动能改变行为，因为签名是**事前**锁定、**可被第三方重算**的：Agent 不能靠换措辞造出新族，也不能靠“我觉得这两个不一样”赖掉合并。

由此得到三条可直接搬的结论（其余是演绎，不当引文用）：

1. **描述维度必须先于候选锁定，且与目标函数无关**（MAP-Elites）。搬过来就是：探针在派发前写死，不能等看到候选再编。
2. **早停／加倍下注在“臂的表现可早期预测”时有效**（Hyperband / SH）。搬过来要**加限制**：跨机制族不适用，因为机制改变常常后段才起效，早期剪枝等于用先验淘汰高潜力族。
3. **停止需要显式的置信／分辨率判据**（Even-Dar 的动作消除）。搬过来就是：差距小于分辨率时判并列，不许宣称最佳。

## 2. 形式化：我把“多样性”换成了一个可算的量

记号：候选集 C；判别探针组 P = (p₁…p_m)，每条 p 是一次**可施加的干预 + 一个可观察的问题**；预测取值 V = {上升, 下降, 不变, 未知}。

- **签名** φ(c) = c 对 p₁…p_m 的预测向量。**覆盖度** = φ(C) 里不同签名的个数，即**族数**，不是候选数。
- φ(c) = φ(c′) ⟹ 二者在 P 下**不可区分**，按同一族处理。注意这只是“不可区分”，**不是**“机制相同”——机制同一性一般不可判定，任何“已证明两者同机制”的说法都是伪证。规范里必须写这个弱化（见 §3 R2 的措辞）。
- 于是“多写几个候选”不再能提高覆盖度；只有**在新探针上有不同预测**才能。这正是 S3 要的**非计数判据**：第三方拿同一张签名表重算即可，不必相信汇总者的品味。
- **探针矩阵的行／列异常就是补搜触发器**：某列全员一致 → 共同盲点（没人检验这个假设）；某列全员“未知” → 无人区分（探针白写，或这一维真没人碰）；某个方向零候选 → 空转。
- **预算分配 = 集合覆盖**：把“仍未被反例击中的族”当成待覆盖元素，把“一次可行的实验／检索”当成能判定若干族的集合 S(e)，成本 t(e)。贪心按 |S(e)|/t(e) 选下一个单元，近似比 H(n)。**停止条件**：没有任何 e 能同时判定 ≥2 个活族，且每个活族都已有 1 个单元——此时边际信息量低于一次实验成本。
- **防锁定 = 跨族不淘汰**：剪枝只在族内做（同族调参互相比较便宜且可比），跨族只按**反例**淘汰。这条是对 SH／Hyperband 的显式限制，不是它的推论。
- **判胜的分辨率**：用同一基线重复测出波动带，声明 MDD；|top1 − top2| < MDD 时判并列。这与 `experiment-protocol.md` §1.3 已有的“判定误差范围”接得上，但要把它变成**结论层**的硬规则，而不只是实验设计时填的一栏。

**无 embedding、无额外工具时怎么近似**：全部靠“人对 4–6 条固定问题做四值预测”这张小表。m=5 时理论格 4⁵，实际有效格通常 3–8 个，人手就能维护；不需要模型、向量或联网。我也试过用字符 3-gram Jaccard 做中文近重复筛查——**实测无效，已放弃**，数据见 §5.4。

### R1 · SKILL.md：在 §1 末尾、示例行（现第 29 行「例如…」）**之前插入**这一节

```
### 先写判别探针，再分路

动手前先写 **判别探针**（`quick` 2 条，`standard`／`deep` 4–6 条），和成功标准放在同一份共同任务书里。每条探针是一句“若对系统施加 X，结果会怎样”：X 必须是真能施加的改变——打乱输入顺序、删掉某类信息、把样本或预算减半或加倍、换一个更弱或不同类型的基线、换一种分布外输入。

探针有两个用途。**去重**：两个候选若在全部探针上预测相同，就当作同一族，不论名字与措辞。**找盲点**：若所有路线在某条探针上预测一致，说明这个假设没有任何路线在检验，下一轮应专门补一路去打它。探针必须可施加、可观察、与目标指标相关；“如果模型更强会怎样”这类写不出施加方式的，不算探针。
```

**为什么**：这是全篇唯一一个**事前**约束多样性的机制。现有 §1 只有“检查方向之间是否只换了说法”（第 26 行）这种不可判定的要求；改成探针后，“只换说法”变成一个能当场算出来的事实。
**代价**：派发前多 3–10 分钟；`quick` 下多 2 条问题。

```
3. 按**可观察预测**归族，不按名称归族：把每个候选在探针组上的预测排成签名，签名相同者并为一族，第三方重算即可复核；术语、领域、措辞都作不了依据。关键假设或失败边界不同的方案应分别保留——它们至少在一条探针上预测不同。区分**常规优化**（调参、换同类工具）与**原理改变**（换问题描述、信息来源、目标或机制）：判据是“若按它声称的因果机制去施加改变，哪条探针会不同”，答不出来的一律按常规优化计。
```

### R3 · SKILL.md §3：**替换第 53、54 行**（原第 5 条“只在有价值时派第二轮”＋第 6 条“每 60 分钟复查”），改为三条

```
5. **按信息量花剩下的预算，不按当前分数**。把剩余预算切成等额单元（一个单元＝一次中等规模检索，或一次实验）。每个单元投出前问一句：“投完之后，哪一族的判定会改变？”答“没有”就换族或收尾。下限与上限：每个尚未被反例击中的族至少拿到 1 个单元；领先路线累计不得超过剩余预算的一半。连续两个单元只让领先路线更好，下一个单元必须用于跨族判别实验。

6. **只在出现具名空白时补搜**，而不是“再多搜一点”。触发条件是：(a) 某条探针上所有候选预测一致——共同盲点；(b) 某条探针没人给出确定预测——无人区分；(c) 某个方向零候选；(d) 两条路线结论相反且各有原始证据。补搜时派一路新的宽泛方向，仍要求独立解决完整目标；需要核查具体争议时单独派验证 Agent。两种都不以“润色赢家”为任务。
```

**为什么**：三件事一次到位。(i) 原来“有价值时补搜”没有判据，现在有 4 个能数出来的触发条件；(ii) 原来“每 60 分钟”是装饰（BRIEF §6 的怀疑成立：`methods.md` 第 12 行自己写了“单纯写进 Skill 的每小时检查不会自动定时”），改成事件边界；(iii) “每族 ≥1 单元 ＋ 领先 ≤50%”是**防首个高分锁定**的硬规则——把 ε-greedy 的 ε 变成一个能查的配额，而不是一句“注意不要过早收敛”。
**代价**：可能把预算花在明显较差的族上；“上限 50%”在只剩 2 族时等于强制对半，深挖会被打断。这是有意的：宁可损失一点收敛速度，也不让一条路线吃掉全部预算。

```
提醒：签名相同（在现有探针下不可区分）：C1, C2；应作为同一族处理，或补充能分开它们的探针
提醒：探针 P2: 所有候选预测一致（degrade），这是共同盲点，下一轮应专门检验它
严格模式：多样性退化（签名单一/碰撞/探针无人区分）。
strict_exit=1
```

demo 里的 C1「用几何约束求解器反推尺寸，约束不完备时退化」与 C2「先建约束图再交给通用求解器反推尺寸并修复过约束」是**我构造的示例**（不是真实研究产出），用来展示这条判据抓住最典型的一类假多样性：同一机制换了一层工程包装，`mechanism_key` 会写成两个不同的值，而签名完全相同。

### 5.4 反例实验：字符 3-gram 相似度在中文机制短句上失效

```
同义改写（应高）              0.132
共词但机制不同（假阳性风险）  0.150
领域不同机制不同（应低）      0.000
```

真正的同义改写只有 0.132，而“共用‘几何约束求解器’但机制相反”的一对有 0.150——**两者没有分离度**：0.6 阈值下都被判“不重复”（假阴性），调低阈值又会假阳性。结论：词面相似度只能当筛查线索，不能当归族判据；我把它默认关闭，并把负结果写成回归测试（`test_lexical_screen_fails_on_chinese_short_sentences`），防止以后有人再把它当主判据。

## 6. 失败、未覆盖、我不确定的地方

1. **预测可被策略性填写**。签名由候选提出者自填；想显得“独立”的 Agent 可以故意在一条探针上填不同值来伪造新族。现有设计只能靠“探针事前锁定 ＋ 复核者用实际干预回测预测”部分缓解，**没有**做到不可伪造。真正的解法是让复核者事后真跑那几条干预——成本高，本设计未强制。
2. **签名碰撞 ≠ 机制相同**，只是“在现有探针下不可区分”。探针组选得差，覆盖度就是自欺。我没有给出“探针组好不好”的判据（可以想到“任意两条都能被某条探针分开”，但那是要求探针组完备，不现实）。
3. **`facts` 模式没有可施加的干预**。替代是“资料层面的判别”（若该说法成立，应能在哪类原始文件／字段里看到什么），**未验证**它在纯文献任务里是否真的比现有做法好。这是本方案最薄的一环。
4. **没有行为对照实验**。我只验证了脚本与文本，没有让两个 Agent 分别用旧版／新版跑同一任务来测“族数”差异。所以“会改变行为”是设计论证 ＋ 可检查产物，不是实测结论。
5. **检索受限**。`web_search` 401，无法确认“当前流行的多 Agent 发散做法”里是否已有人做过同类判据（例如某些 QD 库已把 behavioral descriptor 工程化）。汇总时若能联网，应补查一次，避免把已知工程做法当新设计。
6. **预算比例的来源**。“每族 ≥1 单元、领先 ≤50%”是从集合覆盖“每个元素至少被覆盖一次”推出来的下限，**不是**实验调出来的最优值；只有 2 族时会强制对半，可能过保守。

**S2 可执行**：每条都是“触发条件 → 动作 → 产物”。探针＝派发前的一组问题；签名＝一张四值表；预算单元＝一次检索或一次实验；补搜＝四个具名条件之一；停止＝无实验能判定 ≥2 族。全部不需要额外工具，纸笔可做。
