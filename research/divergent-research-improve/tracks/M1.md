## 2. 归并后的机制族（采纳 5 族）

- **F1 可失败的验证**（D1 主，D2 的措辞等级并入）：已验证 = 可重跑 + 会失败 + 判定者带来新东西；措辞随等级。
- **F2 残渣而非声明**（D2 锚点 + D4 残渣律 + D6 锚点）：checked 要 where+quote；pass 要真实 artifact；引文可抽查。
- **F3 可判别的去重**（D3 签名 + D6 举证倒置 + D2 的 G2）：默认同族，主张不同者给判别性观察；签名相同即同族。
- **F4 成本结构**（D4）：事前只锁三样、交付上限、零结果是合法交付、审计三探针。
- **F5 入口与降级**（D5 + D6 顺序封存 + D2 的判定内联）：三问 gate、视角×预算、L1/L2/L3、RUN.md。

被合并掉的表述（不再单列）：D2 的 differentiation 双向字段并入 F3 的 finalists 双向检查；D3 的独立 check_coverage.py 并入 check_portfolio.py；D4 的 journal.jsonl 与独立 audit.md 未采纳（见下）。

## 3. 主动放弃

- **独立审计文件 audit.md**：第三方审计的三探针压进 agent-contract 的“复核者任务”，避免多一个只在少数场景读的文件。
- **journal.jsonl 顺序账本**：每步一行 JSON 对 quick/standard 过重；保留“时间戳 + 先写盘再读”的轻量版。
- **check_coverage.py 第二个脚本**：签名检查并入现有脚本，少一个入口。
- **向量/字符相似度**：D3 实测 3-gram 无区分度；embedding 违反仅标准库。
- **哈希链**：执行者即记录者，防不住整链重写，还给审计者虚假安全感。
- **强制不同模型**：不可执行，诱导假称。
- **每条路线强制实验**：facts/decision 无实验台，quick 超预算。
- **按阶段拆 phases/*.md**：把“是否执行检查”变成新的可选决策点（D2 的负结果）。

## 4. 冲突解决

- 预算：保留 D5 的 2–3/4/6 视角，补“撞车按一路计”“单模型照实写”，解决原“至少 3 路”与 quick 的冲突。
- “每 60 分钟”：改为事件触发；宿主有定时能力才叠提醒（D2/D3/D5/D6 一致）。
- checked 向后兼容：选择破坏性变更（缺锚点即报错），并在 portfolio-format 写明迁移方式；理由是旧语义正是漏洞入口。
- SKILL.md 篇幅：坚持 ≤25%（实测行 +4.9%、字符 +24.7%、字节 +24.9%），细节移入 references 而非删规则。

## 5. 未被任何路线覆盖的空白

- **facts 模式**没有可施加的干预，判别性观察只能退化为“查哪份资料/做哪个对照”；D3 自认这是最薄处，本轮未解决。
- **无真实 Agent 的 A/B**：所有“会改变行为”的判断都是机制推理 + 合成夹具，不是行为实验。
- **quick 是否真能在 10 分钟内完成**：未计时对照。
- **签名可被策略性填写**：复核者回测成本未测。
