## 4. 成功标准（在看到任何候选之前锁定）

- **S1 防退化**：至少 3 个新检查点或改写，各自能阻止一类可观察的假探索，并给出"如何发现"的具体信号。候选退化行为至少包括（不限于）：同一机制换名当新路线；把报告分工当独立研究；首轮就互相看结果；用 Agent 数量或搜索次数当多样性；未打开原文就写"已核实"；常规调参说成原理创新；无独立评测却写"已证明优于基线"。
- **S2 可执行**：每条新指令 = 触发条件 + 具体动作 + 可观察产物；一个没有额外工具的 Agent 也能执行；不写无法判定的口号。
- **S3 多样性**：方向生成更难被第一批热门方案锚定；给出**非计数**的多样性判据（能被第三方复核）。
- **S4 成本**：`quick` 模式不得重于现状；`SKILL.md` 篇幅增幅 ≤ 25%；新增引用文件只在有独立价值时增加。
- **S5 可验证**：每条改动附检验方式（脚本断言 / 走查样例 / 对照实验 / 审计清单），并说明"生效时观察到什么"。
- **S6 保留内核**：同一完整目标 + 宽泛视角 + 首轮隔离 + 缺口补搜 + 证据与独立评测。
